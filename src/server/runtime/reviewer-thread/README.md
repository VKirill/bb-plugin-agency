# Реестр тредов проверяющего

Модуль помнит скрытый тред проверяющего за парой «проверяющий + линия работы». Координатор запуска к нему не подключён: это делает подзадача AG-151 2/2.

## Таблица `agency_reviewer_thread`

Первичный ключ: `(reviewer_agent_id, line_job_id)`.

| Поле | Смысл |
| --- | --- |
| `thread_id` | Сохранённый тред проверяющего |
| `origin_*` | Первый spawn этого треда (`pluginMetadata`: launch / attempt / job) |
| `state` | `live` — можно продолжать; `dead` — find не возвращает |
| `last_job_id` | Последняя задача проверки, для которой запомнили тред |

`rememberReviewerThread` делает upsert: новый `thread_id` заменяет старый и снова ставит `live`. `origin_*` обновляются только при смене треда.

## Линия работы

`resolveReviewLine(db, reviewJobId)`:

1. Задача не из `agency_auto_review` → `null`.
2. Берём работу W этой проверки.
3. Идём по входам W (`agency_job_input_ref.source_job_id`): источник-автопроверка → её работа; обычная задача с тем же `parent_job_id` → она.
4. Повтор до корня, не больше 20 шагов, посещённые id отсекают цикл.
5. Корень цепочки — id линии.

Повторная автопроверка доработки, у которой входом заключение предыдущей проверки, даёт тот же корень, что и первая проверка.
