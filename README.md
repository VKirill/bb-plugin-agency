# Агентство

Самостоятельный BB-плагин для сотрудников, отделов, поручений и событийной
оркестрации. Сейчас — **прототип интерфейса alpha.12**, а не готовый автономный исполнитель.

Реализованы загрузочная factory, кликабельные экраны, RPC/CLI и сохраняемый входящий
журнал уведомлений с защитой от повторов. Уведомления не запускают агентов.
Доски, профили, правила и вложения работают с примером данных в памяти страницы.
Файлы открываются по клику в закрываемой правой вкладке BB. Нативный Markdown,
редактор и версии в примере; копии предпросмотра сохраняются на основной машине.
В AG-102 приложен «Возможности Markdown.md» с примерами форматирования.
Машины/CLI читаются из BB; политика CLI и opt-in Telegram сохраняются в KV.
[Контракты взаимодействий и готовность](docs/interaction-and-runtime.md).
Изоляция MCP/skills, реальные задания, расписания и диспетчер ещё не реализованы.

Главный экран — задачи по статусам с выбором проекта, отдела или сотрудника справа.
Карточка задачи: работа и обсуждение слева, свойства/файлы/запуски справа.

## Структура

```text
server.ts                    регистрация серверной части
app.tsx                      регистрация страницы и fileOpener BB
host.ts                      запись копий предпросмотра на выбранный host
src/
  shared/                    Zod-схемы и RPC-контракт
  domain/                    модель сотрудников, отделов, задач, запусков и правил
  server/
    register.ts              сборка зависимостей и регистрация RPC/CLI
    db/                      SQLite и append-only миграции
    inbox/                   сохраняемые входящие уведомления
    triggers/                адаптеры источников событий
    runtime/                 проверка возможностей и будущий запуск работников
    dispatcher/              контракты запуска и сверки состояния
  app/prototype/             используемый UI и демонстрационные данные
  app/pages/                 legacy status; будущие рабочие экраны
components/ui/               компоненты из штатного scaffold BB
hooks/, lib/                 поддержка компонентов scaffold
skills/agency/               инструкция использования CLI
tests/                      проверки поведения через SDK harness
docs/                       архитектура, события, API и этапы
```

## Разработка

```sh
npm ci --include=dev
npm run typecheck
npm test
npm run build
```

Для локальной установки в BB из каталога плагина:

```sh
bb plugin install .
bb agency status --json
```

Плагин регистрирует страницу `/plugins/agency/overview` и CLI `bb agency`.
Сборка проверяет артефакты, но не означает установку. Пакет использует SDK 0.4.87,
заявленная совместимость BB `>=0.43.1 <0.44`.

## Данные и откат

Собственная база: `<BB dataDir>/plugins/agency/data.db`. BB владеет соединением и
закрывает его при перезагрузке. Исходники и база раздельны. Артефакты заказов
принадлежат проектам заказов; значения секретов не хранятся в Git и уведомлениях.
Для backup SQLite использовать согласованный snapshot/backup, не копию одного
активного data.db без WAL. Перед будущими миграциями сохранять совместимую копию.

Если плагин установлен, `bb plugin disable agency` выключает его; сохранённые
данные не удалять. В текущей версии нет служб, расписаний и запуска работников,
поэтому отключение не оставляет созданных агентских процессов.
