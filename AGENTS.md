# Интерфейс плагина

Перед изменением UI прочитай DESIGN.md. Используй одну композицию очередей,
подробностей и истории; не вводи новый паттерн для отдельного экрана без причины.
Подключай штатные компоненты BB. При проверке отличай демонстрационный UI от
реального исполнения, не показывай чужие результаты/запуски как данные задачи.
