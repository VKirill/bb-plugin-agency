# Агентство

Кликабельный прототип внутри BB: сотрудники, отделы, проекты, задачи в канбане
и списке, автоматизации, входящие, запуски, знания и настройки.

Выбор CLI, модели, режима разрешений и редактор поручения используют компоненты
BB. Все карточки демонстрационные, изменения до перезагрузки. Реальные
сотрудники, задачи и cron не запускаются. Backend status/notify сохранён.
