# Агентство — обзор для установки

Постоянные сотрудники, отделы, задачи и версии файлов в BB. CLI `bb agency`,
страница `/plugins/agency/overview`. Деморежим — отдельная кнопка, не рабочие данные.

**Runtime:** CRUD всегда. Spawn — штатный `threads.spawn` (скрытый plugin-тред,
pluginMetadata). Исполнение не объявляют без квитанции координатора.
Каталог жив, если запуск ждёт CLI, политики или правила проекта.

**Стартовые отделы.** Кит ставит четырнадцать отделов с регламентом, руководителем,
исполнителями, проверяющим и помощником. Что каждый берёт и какой пул навыков —
[departments.md](skills/agency/references/departments.md). На запуск из библиотеки
отдела — не больше двух навыков. Деньги, кабинет и публикация от имени компании
остаются у владельца.

**Не обещать:** файловую песочницу всех CLI, accept по тексту «готово»,
`waiting_input` из прозы треда. Расписание и webhook в правилах отдела идут через
тот же launch gate, не минуя его.

Введение и границы пакета — корневой README. Контракты: [docs/README.md](docs/README.md).
